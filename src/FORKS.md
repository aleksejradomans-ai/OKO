## [FORK: InboxAnalyst / Telegram Bot API]

**Суть:** Passive Digest — анализ сообщений, поступающих боту, с
"мягкими" паттерн-подсказками (не классификацией). Никакого
автоматического блокирования или переписывания.

**Ключевое архитектурное решение, которое нужно принять перед реализацией:**
Bot API (сообщения боту) vs Telethon/MTProto (личная переписка).
Это две разные модели доступа с разными последствиями для приватности.

**Почему отложено:** Не было ответа на вопрос "а или б" выше.

**Триггер:** Когда будет явный ответ на вопрос про Bot API vs MTProto.
