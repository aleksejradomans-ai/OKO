# Архитектурные инварианты движка «Око»

Публичный реестр. Здесь только свойства движка, которые обязан сохранять любой код: без привязки к машине,
носителям, сетям и процессу разработки. Номер инварианта постоянный; дата — когда правило закреплено.
Отдельные архитектурные решения с обоснованием — `docs/ADR-*.md`.

## Общие принципы

- **INV-01 Fail-closed (15.11.2026).** Любая неопределённость на пути к исполнению — отказ, а не исполнение:
  исключение, отсутствующий обязательный порог (`NO_DATA`), невалидный вход, повреждённое состояние → `HALT`.
  Молчаливое обрезание или подстановка значений запрещены.
- **INV-02 Детерминированный разбор раньше модели (10.11.2026).** Команды к устройствам, вопросы о самой системе и
  «запомни …» разбираются кодом по закрытым правилам до обращения к языковой модели. Модель не вызывает приводы.
- **INV-03 Безличность ответов (10.11.2026).** Системные фразы — без рода и без «я»; роль задаётся кодом, а не
  историей диалога.
- **INV-04 Секреты вне кода (14.11.2026).** Ключи, токены и идентификаторы владельца берутся только из локального
  окружения (`.env`, переменные службы); в репозиторий, журналы и отчёты попадают только факты «значение есть».

## Контуры

- **INV-05 Контур A — устройства (14.11.2026).** Слой Σ (`src/abstraction_layer.py`, шлюз `src/sigma_gate.py`)
  отвечает только за команды к устройствам и неоднозначные команды к железу. Исполнение — только при
  `Authorization = 1` и `SafetyGate = 1`.
- **INV-06 Контур B — общий режим (14.11.2026).** Вопросы о самоидентификации системы закрываются детерминированными
  сторожами кода (`role_guard`, `router`) без математики Σ: вызов приводов блокируется, ответ — сухой, о функциях.
- **INV-07 Host-Only (14.11.2026).** Закрытый режим владельца открывается только по техническому id отправителя из
  локального окружения; текст сообщения («я владелец» и т.п.) роли не играет. Сторожа против выдуманных действий и
  поддельных меток `[PASS|WARN|FAIL]` действуют всегда, в том числе в Host-Only. Тесты режима — под синтетическим id.

## Ядро Σ

- **INV-08 Исходы отказа (15.11.2026).** Кроме `EXECUTE` возможны только `HALT` (бюджет `R_t = 0`, нет авторизации
  или SafetyGate, невалидный вход, `NO_DATA` порога), `OBSERVE` (тревога диссонанса или низкая уверенность
  `C_state < Θ_state`) и `CLARIFY` (слабое или неоднозначное намерение). При `R_t = 0` — строго `HALT`.
- **INV-09 Валидация входов (15.11.2026).** `C_state`, `q_best`, `q_second`, `C_goal`, `D_t` ∈ [0, 1] и конечны;
  NaN, ±Inf, выход за диапазон, вырожденная или не положительно полуопределённая ковариация → `HALT`.
  Ошибки ядра наружу не выходят: результат — `HALT` с причиной.
- **INV-10 Теневой режим по умолчанию (16.11.2026).** Пока `OKO_SIGMA_LIVE` не равен `1`, вердикт Σ только
  считается и пишется в журнал; команда исполняется прежним путём, лишних вызовов устройства нет.
- **INV-11 Интегратор диссонанса (16.11.2026).** Накопление внутри активной сессии — по шагам:
  `D_n = min(1, λ_0·D_{n−1} + (1 − λ_0)·δ_n)`; одно событие (уникальный `event_id`) — один импульс, повтор
  импульса не даёт. Тревога — автомат гистерезиса `A_t ∈ {0, 1}` (вход `D ≥ Θ_crit`, выход `D < Θ_reset`),
  состояние восстанавливается после перезапуска.
- **INV-12 Тревога снимается только подтверждением (16.11.2026).** Активная тревога переживает паузу любой длины;
  ожидание без подтверждения исправности блокировку не снимает. Снятие — только после 5 подтверждённых
  успешных чтений подряд; неудачное или расходящееся чтение сбрасывает счётчик.
- **INV-13 Active Probing только на чтение (16.11.2026).** При тревоге в боевом режиме шлюз выполняет лишь
  контрольное чтение состояния в пределах бюджета `R_t`; команд изменения состояния нет.
- **INV-14 Изменение формул — только с регрессионным тестом (16.11.2026).** Правка формулы ядра закрепляется тестом
  на входном векторе найденной аномалии.

## Журналы и память

- **INV-15 Белый список журнала (15.11.2026).** Теневой журнал Σ пишет только поля белого списка (время, шаг, вид
  команды, признак, ожидаемое и считанное значение, исход, код ошибки, задержка, `seq`, вердикт). Текст ввода и
  ответа, id пользователя и чата, ключи и сырой ответ API — запрещены. Сбой записи на команду не влияет.
- **INV-16 Явное обучение (10.11.2026).** Связка «фраза → штатная команда» закрепляется только явным действием
  владельца и только после исполнения с подтверждённым результатом. Таблица связок ограничена (500 строк, LRU);
  каждое вытеснение журналируется и требует подтверждения.
- **INV-17 Исполнение только через штатный обработчик (11.11.2026).** Память связок лишь выбирает готовую штатную
  команду; исполнение и защита опасных команд — в штатном обработчике устройства.
- **INV-18 Исключённые источники RAG (02.11.2026).** Источники по маске имени (например, справка API ТВ) не идут в
  контекст ответа чата.

## Устройства

- **INV-19 Потолок громкости (16.11.2026).** Шаговые и знаковые команды громкости не поднимают её выше 15;
  выше — отказ и переспрос.
- **INV-20 Знаковые команды (16.11.2026).** «+N» / «−N» / «+» / «++» меняют параметр, изменённый последним в текущей
  сессии (пауза ≤ 60 с); нет такого параметра — `CLARIFY`, ничего не исполняется.

## Песочница

- **INV-21 Песочница без секретов (15.11.2026).** Песочница патчей не копирует файлы секретов и их копии и очищает
  окружение дочернего процесса от секретных имён. Пути патча ограничены песочницей; при сбое песочница
  сохраняется, молчаливой уборки нет.
